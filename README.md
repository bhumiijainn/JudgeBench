# JudgeBench

LLM-as-Judge Evaluation and Bias Analysis Pipeline.

## Overview

JudgeBench evaluates LLM outputs using a structured rubric and provides:

- Pointwise and pairwise evaluation
- Structured judge verdicts
- Robust malformed-JSON handling
- A/B model or prompt comparison
- Position-bias measurement
- Verbosity-bias testing
- Sycophancy/adversarial probes
- Judge validation
- Test-retest consistency
- Token and cost tracking
- Auditable judge logs
- Reproducible evaluation reports
